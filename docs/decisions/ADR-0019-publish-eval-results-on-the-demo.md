# ADR-0019: Publish eval results on the demo site, built from versioned files

## Status
Accepted.

## Context
The eval harness (ADR-0012) produced pass rates, costs and model
rationales, but only in GitHub job summaries and JSON files in the repo.
A visitor to the demo saw the agent work once. They never saw the evidence
that it works reliably, or the problems the evals caught along the way.
Those problems are the more interesting half of the story.

## Decision
- **An Evals page in the demo frontend (`/evals`).** It shows:
  - the latest recorded run: pass rate, cost, and gate status
  - every scenario, with its expected answer and why, and each trial's
    grades and Claude's own rationale
  - the run history, with what changed before each run
  - "what the evals caught", linking to the decision records
- **The page is built from the repo, not served by an API:**
  - The scenario definitions come from `backend/evals/scenarios.json`,
    generated by `python -m evals.scenarios`. A test fails if it drifts
    from `SCENARIOS`.
  - The recorded runs come from `backend/evals/results/*.json`, each
    loaded lazily as its own chunk.
  - Frontend Deploy also triggers on changes to either, so a recording
    run that gets merged republishes the page.
- **History notes and findings are curated by hand** in
  `frontend/src/evals/data.ts`. They're the narrative, and they belong
  with the page, not in the harness's output.

## Consequences
- The results are exactly what's in the repo at the deployed commit: no
  extra infrastructure, and nothing to keep in sync at runtime. The page is
  only as fresh as the last merged recording, which is the right
  granularity: unmerged runs haven't been reviewed.
- Rationales are shown verbatim. Reading them on this page is how a second
  symptom of the truncation bug was spotted: tool-call syntax leaked into a
  rationale. That's now caught by a gating grader (ADR-0012).
- Each recorded run adds about 60 KB of JSON, loaded only when the page
  opens. If the history grows large, older runs can move to a summary
  file.
